# s3okit

Tooling to remodel TA:Recoil's TA / Core Contingency / Battle Tactics units as textured S3O models, with wrecks and
generic scrap heaps. **Start with `../s3o-remodel-handoff.md`.** `manifest/manifest.md` lists every requested unit and
what it maps to in the repo (regenerate with `python3 make_manifest.py`). `examples/` holds the Flash and a test heap.
